# Phila — Disease Hero Image Generation Prompts

## Specs

- **Aspect ratio:** 4:5 portrait (mobile-optimised)
- **Target dimensions:** 1080x1350px
- **Target file size:** ~250kb webp
- **Filename convention:** \hero-{slug}.webp\ matching the slug in diseases.json

## Style rules

- **Render style:** 3D realistic, Pixar-quality, cinematic depth of field, warm soft lighting
- **No text:** Absolutely no text/letters/numbers in any image (multilingual app — text rendered in HTML)
- **Composition:** Top-to-bottom flow in three stacked sections (matches mobile scroll direction)
- **SA representation:** Distribute people evenly across Black, Coloured, Indian/Asian, and White South Africans across the image library
